### **Clone the repo**

```bash
git clone https://github.com/fkk989/medblocks-assignment.git
cd medblocks-assignment
```

## ⚙️ Setup Instructions


#### Install dependencies

```bash
npm install
```

#### To start the frontend in dev mode

```bash
npm run dev
```

#### To start the frontend in prod mode

- build the project

```bash
npm run build
```

- start the project

```bash
npm run preview
```
